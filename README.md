# Saudi Lawyer Skill · مهارة المحامي السعودي

مهارة (Agent Skill) تجعل وكيل الذكاء الاصطناعي، مثل Claude Code، يعمل كمساعد قانوني متخصص في الأنظمة السعودية: صياغة صحف الدعاوى والمذكرات، تكييف النزاع، تحديد المحكمة المختصة، والاستشهاد بالمواد النظامية.

An Agent Skill that turns an AI agent (e.g. Claude Code) into a legal assistant for Saudi Arabian law: drafting statements of claim and memos, classifying disputes, identifying the competent court, and citing regulations.

## المزايا

- صياغة صحيفة دعوى وفق المادة (41) من نظام المرافعات الشرعية.
- مذكرات جوابية ولوائح اعتراضية بترتيب الدفوع الشكلية ثم الموضوعية.
- تنبيه إلى الإجراءات السابقة للقيد والمواعيد النظامية.
- قائمة مرجعية بأبرز الأنظمة السعودية والجهات القضائية.
- قاعدة صارمة: لا اختلاق لأرقام المواد أو الصكوك أو المبادئ.

## التثبيت

### Claude Code (على مستوى المستخدم)

```bash
git clone https://github.com/<your-username>/saudi-lawyer-skill.git ~/.claude/skills/saudi-lawyer
```

### على مستوى مشروع محدد

```bash
git clone https://github.com/<your-username>/saudi-lawyer-skill.git .claude/skills/saudi-lawyer
```

### Claude.ai

اضغط المجلد كملف `.zip` وارفعه من **Settings → Capabilities → Skills**.

## الاستخدام

تُفعَّل المهارة تلقائيًا عند طرح سؤال قانوني سعودي، مثل:

- "اكتب لي صحيفة دعوى مطالبة مالية ضد مقاول لم يُكمل العمل."
- "فُصلت من عملي دون سبب، ما حقوقي وما الإجراء؟"
- "ما المحكمة المختصة بنزاع بين شريكين في شركة ذات مسؤولية محدودة؟"
- "جهّز مذكرة جوابية أدفع فيها بعدم الاختصاص."

## إخلاء المسؤولية

مخرجات هذه المهارة معلومات ومسودات استرشادية، **وليست استشارة قانونية**. تحقق من النصوص النافذة في [هيئة الخبراء بمجلس الوزراء](https://laws.boe.gov.sa)، واستشر محاميًا مرخّصًا قبل أي إجراء قضائي.
